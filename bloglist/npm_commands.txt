-------------------------------------
FRONTEND: bloglist-frontend
-------------------------------------

Run these commands inside the bloglist-frontend folder.


npm install

Installs all dependencies defined in package.json and creates node_modules.


npm run dev

Starts Vite in development mode.

Usually available at:
http://localhost:5173


npm run build

Builds the frontend for production.

Creates:
dist/


npm run preview

Serves the contents of dist/ locally so you can test the production build.


npm run lint

Runs ESLint to detect code errors and problems according to the configured rules.


npm test

Runs Vitest in interactive/watch mode.


npm test -- --run

Runs the Vitest tests once instead of staying in watch mode.



-------------------------------------
BACKEND: backend
-------------------------------------

Run these commands inside the backend folder.


npm install

Installs all dependencies defined in package.json and creates node_modules.


npm run dev

Starts the backend with Nodemon.

Nodemon automatically restarts the server when it detects changes.


npm start

Starts the backend using the production script.

In this project, the script is:

cross-env NODE_ENV=production node index.js

Therefore, npm start sets NODE_ENV=production.


npm run start:test

Starts the backend using:

NODE_ENV=test node --watch index.js

Used for working with the testing configuration while automatically
restarting the server when files change.


npm test

Runs the backend tests using Node's Test Runner.

The script also uses:

--test-concurrency=1

This makes the tests run sequentially.


npm run lint

Runs ESLint on the backend.

=====================================
3. WHAT DOES --prefix MEAN?
=====================================

--prefix tells npm to execute the command as if it were being run
inside the specified folder.

For example:

npm run dev --prefix client

means:

"Run the dev script from the package.json inside client."

It is approximately equivalent to:

cd client
npm run dev


Likewise:

npm run dev --prefix server

is approximately equivalent to:

cd server
npm run dev

4. THE THREE package.json FILES
=====================================


bloglist/package.json

Controls the monorepo and coordinates the frontend and backend.


bloglist/client/package.json

Controls the React/Vite frontend.


bloglist/server/package.json

Controls the Express/Node backend.



=====================================
5. MONOREPO package.json
=====================================

Our bloglist/package.json contains:

{
  "scripts": {
    "dev": "concurrently \"npm run dev --prefix server\" \"npm run dev --prefix client\"",
    "build": "npm run build --prefix client",
    "start": "npm start --prefix server"
  }
}


This means:


npm run dev
Runs frontend + backend.


npm run build

Builds the frontend.


npm start

Starts the backend in production, which also serves the
compiled frontend.

=====================================
10. IMPORTANT CONCEPT
=====================================

The package.json files are not interchangeable.

client/package.json
Controls the frontend.

server/package.json
Controls the backend.

bloglist/package.json
Coordinates both projects.

The monorepo does not replace the individual package.json files.
It simply uses --prefix to execute their scripts from one place.
